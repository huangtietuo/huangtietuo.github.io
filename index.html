03 — 自建技能 / workshop

我把日常反复做的事，固化成一个个可复用的 Agent 技能（Skill）：跑通一次，之后一句指令就交付。 下面这 7 个是我自己在用的主力技能，其中「三虾流水线」是公众号内容的生产主干。

内容流水线： 选题虾 📰 → 文案虾 ✍️ → 审核虾 🔍 → 发布
📄 论文排版技能
$ /thesis-format-docx

把论文一键排版成符合中文格式规范的 Word，并导出同名 PDF 定版。支持 Markdown / 纯文本 / Word / PDF 四种输入，统一入口自动路由。

4 种输入 OMML 原生公式 v1.4.5
解决什么：Word 来源公式无损还原、Markdown 的 LaTeX 公式渲染成原生公式对象，不再手动重敲一遍公式。
📰 选题虾
$ /xuan-ti-xia

内容流水线第一环：收集热点、整理口水稿、挖掘主题，为文案虾提供输入。支持口水稿、思路想法、热点抓取三种输入方式。

热点抓取 口水稿整理 选题库沉淀
解决什么：把随口说的一段想法，整理成可写的结构化主题，选题自动存进题库，不再缺选题。
✍️ 文案虾
$ /wen-an-xia

流水线核心主力：大纲生成 → 初稿写作 → 润色去 AI 味 → 多平台改写 → 生成索引。输出符合个人风格、直接可用的成稿。

大纲 / 初稿 Humanizer 去 AI 味 多平台改写
解决什么：公众号、小红书、知乎、今日头条一套内容多平台适配，并且去掉那股 AI 味。
🔍 审核虾
$ /shen-he-xia

流水线第三环：对成稿做 6 维度质量审核——主标题吸引力、小标题简洁性、数据准确性、逻辑合理性、表达风格、清除废话，达标才放行。

6 维审核 发布前置卡口
解决什么：在发布前把 AI 味、硬凑的案例、不准确的数据和废话拦下来，不合格就打回重写。
🎬 video-cut
$ /video-cut

基于 ChatCut 的对话式剪辑：把口播 / 采访 / 探访 / 录屏等实拍素材剪成可发布的短视频。AI 出剪辑方案 → 初版 → 按反馈迭代 → 加字幕 → 包装 → 封面与文案 → 导出。

对话式剪辑 字幕 + 封面 ChatCut MCP
解决什么：不用学剪辑软件，用说话的方式把素材剪成成片，反馈即改。
📱 video-001
$ /video-001

AI 日报竖屏视频全自动流水线：新闻内容 → Edge-TTS 配音 → 逐句测量时间轴生成字幕 → 竖屏模板渲染 → 输出 1080×1920 MP4 并推送飞书。

1080×1920 竖屏 TTS + 字幕 飞书推送
解决什么：每日无人值守跑完「采集 → 成片 → 推送」，我手机上就能收到当天日报视频。
🎙️ live-to-wechat-article
$ /live-to-wechat-article

把直播 / 访谈 / 演讲逐字稿，按 ima「用户故事·专访」栏目的编辑方法整理成公众号文章；成稿后自动回读，逐条核对事实与结构再输出。

逐字稿成稿 回读核对 专访体
解决什么：不是做摘要，是编辑成可发布的稿子，每个人名、数字、案例归属都能回到逐字稿核对。
